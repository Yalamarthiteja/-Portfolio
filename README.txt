# Ramteja Yalamarthi — Cyber Security Portfolio

## Files
- `index.html` — portfolio page
- `style.css` — design and responsive layout
- `script.js` — navigation and scroll animations
- `resume.pdf` — add your own PDF resume with this exact filename

## Run locally
1. Put all files in the same folder.
2. Double-click `index.html`, or open it with a browser.
3. For the best development experience, use VS Code + Live Server.

## Important edits before publishing
Open `index.html` and replace:
- `your.email@example.com`
- `https://github.com/`
- `https://www.linkedin.com/`
- `College / University Name`
- school/college names
- certification names and links
- project descriptions and GitHub links

Only list skills/tools you actually know or are actively learning.

## Publish for free with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `resume.pdf`.
3. Open repository Settings → Pages.
4. Choose the main branch as the deployment source.
5. GitHub will provide your live portfolio URL.
